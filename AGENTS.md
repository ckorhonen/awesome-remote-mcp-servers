# Repository agent guide

## Repository workflow and completion

This Markdown catalogue records remote services, authentication, and maintainers. Apply `CONTRIBUTING.md` requirements for official ownership, stability, active maintenance, and OAuth. Preserve table schema and consult authoritative service docs before editing entries.

No application or build/test/lint command exists. Check Markdown, links, and duplicates; distinguish documented endpoints from authenticated operational checks. Do not grant OAuth scopes, create accounts, send private inputs, or connect servers for editorial validation. Existing inconsistencies do not authorize weakening contribution rules.

Continue the authorized change through relevant validation and repair of failures it causes; preserve unrelated work. Report checks actually run, commands only inspected, and exact missing prerequisites. Ask only when a material decision, missing authorization, or required input blocks progress; continue independent reversible work. Existing mandatory contribution and validation gates still apply.
